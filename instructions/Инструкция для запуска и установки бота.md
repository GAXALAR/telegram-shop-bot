# Инструкция для покупателя: установка и запуск бота

## Что входит в комплект

- `launcher.bat` — запуск окна настройки;
- `launcher.py` — программа настройки и запуска;
- `tg_bot_shop_mulrigoods.py` — файл бота;
- `requirements.txt` — список необходимых библиотек;
- `catalog.json` — каталог товаров;
- файлы `goods_*.txt` — остатки цифровых товаров.
- `welcome_image.jpg` — появится в папке после загрузки изображения приветствия.

Не переименовывайте и не перемещайте файлы по отдельности: они должны оставаться в одной папке.

## Что потребуется

- Windows 10 или Windows 11;
- Python 3.10 или новее;
- аккаунт Telegram и подключённый платёжный провайдер;
- токен Telegram-бота, платёжный токен и числовой Telegram ID администратора;
- подключение к интернету.

### Установка Python

Если Python ещё не установлен, скачайте его с [официального сайта Python](https://www.python.org/downloads/). При установке включите **Add python.exe to PATH**. Для окна запуска также необходим компонент Tcl/Tk; обычно он включён в установщик Python для Windows.

## Первый запуск

1. Распакуйте весь комплект в отдельную папку, например `C:\Bots\MyShopBot`.
2. Дважды щёлкните `launcher.bat`.
3. В окне проверьте статусы Python и `aiogram`. Если `aiogram` не установлен, нажмите **Установить aiogram** и дождитесь сообщения об успешной установке. Для установки нужно подключение к интернету.
4. Заполните три поля:
   - **Токен Telegram-бота** — токен бота, созданного через [@BotFather](https://t.me/BotFather).
   - **Платёжный токен** — токен провайдера для Telegram Payments.
   - **Telegram ID администратора** — числовой ID аккаунта, который будет управлять каталогом и получать уведомления о продажах. Это не имя пользователя и не номер телефона.
5. Нажмите **Сохранить и запустить**. Бот откроется в отдельном окне консоли.
6. Найдите своего бота в Telegram, отправьте `/start` и проверьте, что отображается каталог.

После первого запуска внизу чата появится постоянная кнопка **«🛍 Открыть каталог»**. Нажимайте её, чтобы вернуться к товарам; повторно вводить `/start` не нужно.

Покупатели видят название и цену товара, но не видят количество оставшихся ключей. Администратор может проверить остаток в панели `/admin`.

Поля токенов скрыты. Для проверки введённого значения включите флажок **Показывать токены**. Вставить текст можно сочетанием `Shift+Insert` или правым щелчком мыши через пункт **Вставить**.

## Важные файлы

- `config.json` создаётся запускателем и содержит ваши токены и ID администратора. Не пересылайте его, не публикуйте и не загружайте в общие хранилища. При передаче комплекта другому владельцу удалите свой `config.json`.
- `catalog.json` хранит товары, названия, цены и имена файлов остатков. Не удаляйте его, если хотите сохранить настроенный каталог.
- В каждом `goods_*.txt` хранится запас соответствующего товара: одна позиция на строку. Не помещайте несколько отдельных ключей в одну строку.

Если `catalog.json` отсутствует, бот создаст каталог с начальными товарами. При отсутствии файла остатка бот создаст пустой файл; товар появится в продаже, но купить его нельзя, пока не добавлен запас.

## Управление магазином в Telegram

Откройте чат с ботом от имени администратора и отправьте `/admin`. В меню доступны кнопки:

- **Каталог** — показать товары, цены и остатки;
- **Добавить товар** — введите запрошенную строку `id | Название товара | цена`, например `new | НОВЫЙ ТОВАР | 1599`;
- **Изменить цену** — выберите товар и введите новую цену в рублях;
- **Удалить товар** — выберите позицию и подтвердите удаление. Сам файл остатков останется на диске;
- **Приветствие** — изменить текст, загрузить новое изображение или удалить текущее.

Для добавления изображения нажмите **Загрузить изображение** и отправьте фотографию в чат с ботом. Изображение и текст сохраняются на компьютере вместе с настройками бота и отображаются покупателю при `/start`. Чтобы изменить текст или картинку, повторите соответствующее действие в меню. При передаче проекта другому владельцу передайте актуальное изображение, если оно используется; не передавайте свои токены и `config.json`.

### Как загрузить изображение приветствия

1. Убедитесь, что бот запущен, и откройте с ним личный чат именно с того Telegram-аккаунта, чей ID указан в `ADMIN_ID`.
2. Отправьте `/admin`, затем нажмите **Приветствие** → **Загрузить изображение**.
3. Не переходя в другой чат, прикрепите картинку как **Фото/видео** и отправьте её отдельным сообщением. Не выбирайте отправку как **Файл** и не добавляйте фото к текстовому сообщению.
4. Дождитесь ответа **«Изображение приветствия сохранено»**. Затем отправьте `/start`, чтобы проверить приветствие.

При успешной загрузке изображение сохраняется рядом с файлами бота под именем `welcome_image.jpg`; его путь записывается в `config.json`. Если появилось сообщение об ошибке, попробуйте отправить изображение заново как фото в том же личном чате. Проверьте, что бот работает и вы отправляете фото с аккаунта администратора.

Добавить запас можно командой, отправив ID и ключи отдельными строками:

```text
/add vpn_month
КЛЮЧ-001
КЛЮЧ-002
```

Добавление товара меняет каталог, но не создаёт для него ключи. Сначала добавьте товар, затем пополните остаток.

Команда `/admin` сама по себе не выдаёт права. Панель и её действия доступны только аккаунту, чей числовой Telegram ID указан как `ADMIN_ID` в настройках.

## Остановка и повторный запуск

Чтобы остановить бота, закройте отдельное окно консоли, в котором он работает. Для запуска снова откройте `launcher.bat` и нажмите **Сохранить и запустить**. Не запускайте один и тот же бот одновременно в нескольких окнах: Telegram может отключить один из экземпляров.

Если бот не запускается, проверьте интернет, версию Python и статусы в окне запуска. Ошибки подключения или авторизации отображаются в консоли бота. Для оплаты убедитесь, что платёжный токен относится к подключённому провайдеру и подходит для выбранного режима оплаты.

## Безопасность

- Никому не передавайте `config.json` и токены. Если токен стал известен посторонним, отзовите его у соответствующего сервиса и создайте новый.
- Не отправляйте покупателям свои файлы остатков с действующими ключами.
- Передавайте комплект без собственных конфигураций и секретов.
