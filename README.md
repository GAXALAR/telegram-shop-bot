# Telegram Shop Bot

Мини-магазин цифровых товаров для Telegram на Python с использованием aiogram.

## Что умеет бот
- показывает каталог товаров;
- принимает оплату через Telegram Payments;
- управляет товарами через админ-панель;
- позволяет менять приветствие и цену;
- выдаёт доступ к цифровому товару после оплаты.

## Структура проекта
- `tg_bot_shop_mulrigoods.py` — основная логика бота;
- `launcher.py` — GUI для настройки токенов и запуска;
- `catalog.json` — каталог товаров;
- `config.json` — локальные настройки бота (не загружается в Git);
- `goods_*.txt` — файлы остатков/товаров (не загружаются в Git по умолчанию);
- `requirements.txt` — зависимости проекта.

## Установка

1. Установите Python 3.10+.
2. Установите Git:
   - https://git-scm.com/download/win
3. Создайте виртуальное окружение:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

4. Установите зависимости:

```powershell
pip install -r requirements.txt
```

5. Запустите настройщик:

```powershell
python launcher.py
```

6. Вставьте свои токены Telegram и платёжного провайдера, затем сохраните и запустите бота.
